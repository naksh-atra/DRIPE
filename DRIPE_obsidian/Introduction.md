# DRIPE: Drug Repurposing Intelligence Engine

> AI-powered drug repurposing using knowledge graphs, GNNs, and LLM reasoning.

## Project Overview

DRIPE discovers novel therapeutic uses for existing drugs by analyzing:
- Knowledge graphs (drug-disease relationships)
- Graph Neural Networks (link prediction)
- Literature and clinical data (RAG)
- Safety profiles and equity considerations
